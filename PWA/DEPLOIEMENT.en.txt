S2A PILOT 1.11.10 BETA / BRIDGE 1.6.33 BETA — UPDATE

Back up the installed files and preserve previous release archives. Extract the Pilot ZIP and copy its contents into the existing Pilot directory, replacing matching files. Preserve copilot/config.php and the relay's private storage. Private configuration and server logs are excluded.

Update copilot/ and Bridge 1.6.33 together. Clear any CDN cache if needed, then refresh Pilot while playback is stopped. Pilot must display 1.11.10 beta. Install Bridge from its separate ZIP or the copy bundled with Pilot.

In Bridge Show, open Copilot. Enable remote controls, change the four-digit code if needed, then select Apply. Pilot does not need to be open. On a phone, scan the QR code and choose Remote control; enter the code to access QLab GO, play/pause, previous/next and root-cue selection. Selection alone does not start playback.

Changing the code removes existing control grants and cancels pending commands. Affected users must select Remote control again and enter the new code. Five incorrect guesses from one network address trigger a five-minute lockout. The PIN is never part of the QR link or shared show state. Older Bridge versions remain read-only.

Copilot uses one halo, preferring the timed child cue. Only for Bridge, when no cue is playing or paused, QLab selection previews the selected number and timeline. Pilot-only behavior is unchanged. Each new active cue is placed 20 px below the timeline; manual scrolling remains free between cue changes. Bridge Show uses Iceman and displays the estimated finish of the currently displayed number (later QLab numbers are excluded), excluding GO waits. Paused estimates assume an immediate resume. Unknown durations are stated explicitly, and estimates are hidden when synchronization is lost.

Relay migrations preserve invitations, members and Backstage notes. Beta changes remain separate from main. No production deployment is performed automatically.

Marker editing: use the pencil in Show to set minutes:seconds.milliseconds. The marker time is saved in Bridge and shared with Copilot; QLab media keep their existing schedule.

Cue types: new imports preserve types and per-type descriptions. Reimport older numbers from their Pilot export to recover metadata discarded by older Bridge versions. Filters affect display only, never QLab playback.

Install Bridge 1.6.33 for the pencil positioning fix; the first-cue preview fix is included in Copilot. Refresh Copilot on connected devices after deploying copilot/ and the updated Pilot files.
