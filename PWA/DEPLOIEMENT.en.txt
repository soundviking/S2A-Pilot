S2A PILOT 1.11.2 BETA / BRIDGE 1.6.29 — UPDATE

Back up the installed files and keep earlier release archives. Extract the Pilot ZIP and copy its contents into the existing Pilot directory, replacing matching files. Do not delete the remote directory.
Preserve the existing copilot/config.php and the relay’s private storage. Neither private configuration nor server logs are included in this release.
Upload all updated files together, including copilot/, compat/, diagnostics/, Bridge/, index.html, app.js, i18n-catalog.js, copilot-host.js, toolbox.css, service-worker.js and version.json. Clear any CDN cache if necessary and refresh Pilot while playback is stopped. The displayed version must be 1.11.2 beta.

Each new Copilot share receives a random four-digit remote control code. Change it in the Copilot popup and select Apply. Only Remote control users need this code. It is never included in the QR link or shared show state. Changing the code removes previous remote grants and cancels pending commands; affected users must select Remote control again and enter the new code. Five incorrect guesses from one network address trigger a five-minute lockout.

Install Bridge 1.6.29 from the separate ZIP or the copy included with Pilot. It retains both Intel and Apple Silicon architectures, opens Show in Iceman, and uses the amber BRIDGE icon with cyan wings.
Database migrations preserve invitations, members and Backstage notes. Older Pilot shares cannot accept remote commands until the host configures a code.
This release has been prepared for installation and has not been deployed automatically.
