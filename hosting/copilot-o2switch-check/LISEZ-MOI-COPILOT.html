Préparer Copilot chez o2switch

Vous n’avez pas besoin de savoir programmer. PHP est exécuté par l’hébergement : vous avez seulement à déposer puis décompresser un petit ZIP.

Ce premier paquet vérifie l’hébergement.
Il n’active pas encore Copilot, ne crée aucune session et n’est pas connecté à Pilot. Après ce test, envoyez l’adresse de la page dans notre conversation : le raccordement du module viendra ensuite. Tout reste dans le dossier bêta.

Les cinq étapes

  1. Connectez-vous à votre cPanel o2switch. Ouvrez Gestionnaire de fichiers. Vous pouvez aussi utiliser votre logiciel FTP habituel.
  2. Ouvrez le dossier de la bêta existante. C’est celui qui correspond à https://s2a-production.com/S2A-Pilot-Beta/. Il contient déjà l’index.html de Pilot. Il s’appelle normalement S2A-Pilot-Beta, souvent sous public_html. Ne changez pas le dossier stable S2A-Pilot.
  3. Envoyez le ZIP de préparation. Avec Charger ou Téléverser, déposez S2A-Copilot-Preparation-o2switch-beta.zip dans ce dossier bêta. Vous n’avez pas à ouvrir les fichiers PHP.
  4. Décompressez le ZIP. Revenez au gestionnaire, sélectionnez-le et choisissez Extraire. Le dossier de destination doit rester S2A-Pilot-Beta. Un nouveau sous-dossier copilot-test apparaît. Aucun fichier index.html de Pilot n’est fourni dans ce ZIP, donc il ne le remplace pas. Si ce sous-dossier existe déjà et contient un autre essai, arrêtez-vous et prévenez-moi avant d’écraser quoi que ce soit.
  5. Ouvrez la page de vérification. Allez à https://s2a-production.com/S2A-Pilot-Beta/copilot-test/, puis appuyez sur Tester la connexion. Envoyez-moi cette adresse ou utilisez Copier le diagnostic et collez le résultat dans notre conversation.

Ce que vous devez obtenir

Une page sombre avec le logo S2A et cinq vérifications. Le bouton confirme si le navigateur reçoit bien une réponse PHP. Des points « À vérifier » ne veulent pas dire que vous avez mal installé : nous les réglerons à partir du diagnostic.

Si quelque chose ne s’affiche pas

  • Page introuvable : le ZIP a peut-être été extrait dans un dossier supplémentaire. Le chemin doit se terminer par S2A-Pilot-Beta/copilot-test/index.php, sans second dossier du même nom.
  • Le fichier est téléchargé ou du code PHP apparaît : PHP n’est pas exécuté dans ce dossier. N’essayez pas de modifier le code ; envoyez-moi l’adresse.
  • PHP trop ancien : ouvrez Sélectionner une version de PHP dans cPanel pour examiner la configuration. Nous vérifierons d’abord le périmètre du réglage pour ne pas changer les autres sites. La cible de ce test est PHP 8.2 ou plus récent.
  • Base automatique non disponible : le diagnostic mentionnera pdo_sqlite. C’est une extension à vérifier dans cPanel, pas une base MySQL à créer. Ne décochez pas les extensions déjà présentes.
  • Emplacement privé à vérifier : ne changez aucune permission. Ce test ne crée pas encore de stockage ; nous confirmerons l’emplacement au raccordement.

Après la vérification

Nous préparerons le véritable relais et le branchement dans Pilot : QR code, nom à l’entrée, écrans connectés, révocation individuelle et affichage Show en lecture seule. Ce paquet ne contient pas encore ces fonctions.

Vous pouvez retirer le dossier copilot-test pour supprimer ce diagnostic. Il ne stocke aucun spectacle. Le push GitHub et le dépôt sur votre hébergement sont deux opérations différentes.
